# Вступительные испытания

1. Прием на обучение проводится:
   - По программам бакалавриата и специалитета: по результатам ЕГЭ и/или внутренних вступительных испытаний; без вступительных испытаний для определенных категорий; без проведения вступительных испытаний на места в пределах отдельной квоты
   - По программам магистратуры: по результатам внутренних вступительных испытаний

2. МАИ устанавливает перечень вступительных испытаний и их приоритетность для ранжирования списков поступающих.

3. Для поступающих на базе среднего общего образования устанавливаются общеобразовательные вступительные испытания:
   - Вступительное испытание-1: русский язык
   - Вступительное испытание-2 и испытание-3: профильные общеобразовательные испытания

4. При определении иностранного языка в качестве вступительного испытания:
   - Поступающие могут использовать результаты ЕГЭ по любому иностранному языку (кроме направления 45.03.02 Лингвистика - только английский)
   - МАИ проводит внутреннее вступительное испытание только по английскому языку

5. Для поступающих на базе профессионального образования МАИ устанавливает:
   - Письменную форму проведения испытаний или с применением дистанционных технологий
   - Вступительные испытания в количестве, равном количеству общеобразовательных вступительных испытаний

6. Право сдавать внутренние общеобразовательные вступительные испытания имеют:
   - Лица, поступающие на места в пределах отдельной квоты
   - Инвалиды (в том числе дети-инвалиды)
   - Лица, указанные в части 5.1 статьи 71 Федерального закона №273-ФЗ
   - Иностранные граждане
   - Поступающие с документом о среднем общем образовании, полученным в иностранной организации

7. Граждане Республики Беларусь вправе использовать результаты централизованного тестирования или экзамена.

8. Поступающий может использовать результаты ЕГЭ и/или внутренних вступительных испытаний. Засчитывается наиболее высокий результат.

9. Максимальное количество баллов для каждого вступительного испытания составляет 100 баллов.

10. МАИ проводит внутренние вступительные испытания очно и/или с использованием дистанционных технологий.

11. Результаты внутренних вступительных испытаний действительны при приеме на учебный год, на который осуществляется прием.

12. Поступающий сдает каждое внутреннее вступительное испытание однократно.

13. Внутренние вступительные испытания проводятся на русском языке и/или на иностранном языке.

14. Лица, не прошедшие вступительное испытание по уважительной причине, допускаются к его сдаче в другой группе или в резервный день.

15. При нарушении поступающим правил приема составляется акт о нарушении и о непрохождении вступительного испытания без уважительной причины.

16. Результаты вступительного испытания объявляются на официальном сайте в течение трех рабочих дней после проведения.

17. Поступающий имеет право подать апелляцию о нарушении порядка проведения вступительного испытания и/или о несогласии с полученной оценкой.
